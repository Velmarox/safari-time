# Symbol art

Drop one PNG per symbol in this folder using **exactly** these filenames. The
game probes for each file on load and falls back to a built-in CSS tile for
any that are missing, so you can add them one at a time.

| File           | Symbol    | Notes                                         |
| -------------- | --------- | --------------------------------------------- |
| `j.png`        | J         | lowest pay                                    |
| `q.png`        | Q         |                                               |
| `k.png`        | K         |                                               |
| `a.png`        | A         |                                               |
| `giraffe.png`  | Giraffes  |                                               |
| `zebra.png`    | Zebras    |                                               |
| `rhino.png`    | Rhinos    |                                               |
| `elephant.png` | Elephants |                                               |
| `lion.png`     | Lions     | highest pay                                   |
| `wild.png`     | WILD      | expands to full reel; sticky in Free Games    |
| `africa.png`   | Africa    | scatter - 3/4/5 anywhere = 10/15/20 free games |

Recommended: square, 512x512, transparent or framed background, under 150 KB
each. The "Wildlife Montana" sheet and the Africa medallion you supplied need
slicing into these individual files.
